⚡ 绑定百度网盘 Cookie / BDUSS

📖 如何获取 BDUSS (无需申请任何开发者应用):
  1. 在电脑浏览器中打开并登录 pan.baidu.com。
  2. 按键盘 F12 打开开发者工具，点击顶部的 Application (应用程序) 标签。
  3. 在左侧展开 Cookies ➡️ 点击 https://pan.baidu.com。
  4. 找到名为 BDUSS 的行，双击复制其 Value (或整段 Cookie) 粘贴到下方即可。
