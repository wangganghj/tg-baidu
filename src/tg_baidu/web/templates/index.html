⚡ 绑定百度网盘 Cookie / BDUSS

📖 获取完整网盘 Cookie (包含目录浏览与转存权限):
  1. 在电脑浏览器中打开并登录 pan.baidu.com。
  2. 按 F12 打开开发者工具，切换到 Network (网络) 标签。
  3. 按 F5 刷新网页，在网络请求列表中点击任意请求（例如 list 或 main）。
  4. 在右侧 Headers (标头) ➡️ Request Headers (请求标头) 中找到 Cookie，复制整段值粘贴到下方即可（或复制 Application 中的 BDUSS）。
